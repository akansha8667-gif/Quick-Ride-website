# Quick Ride 🚖

A full stack ride booking web application.

## Tech Stack
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## Features
- User Authentication
- Ride Booking
- Ride History
- Payment Integration
- Driver Dashboard

## Database Setup
Import `database/quickride.sql` into phpMyAdmin.

## Run Project
http://localhost/Quick-Ride
